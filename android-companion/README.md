# Quant Bot Companion

یک اپ سبک اندرویدی برای مشاهده آخرین وضعیت GitHub Actions ربات.

## ویژگی‌ها
- ذخیره نام مخزن در گوشی
- نمایش آخرین Workflow Run از GitHub API
- باز کردن مستقیم صفحه Actions
- بدون نیاز به سرور اختصاصی یا سرویس پولی
- مناسب برای مخزن عمومی؛ برای مخزن خصوصی، مشاهده وضعیت از API عمومی نیازمند احراز هویت است و در این نسخه عمداً توکن داخل APK قرار داده نشده است.

APK با GitHub Actions ساخته می‌شود و نیازی به Android Studio روی گوشی ندارد.
