# Quant Bot V30.6.0

## Main changes
- Session-specific weighting: London/NY overlap highest, Asia selective.
- Asia-Europe overlap enabled and weighted separately.
- New York confidence threshold raised because it was the weakest session in the prior sample.
- Defensive per-symbol filters for previously loss-making symbols: ADA, AVAX, BTC, DOGE, SUI, TON, ZEC.
- Strict symbols require stronger confluence: Fibonacci OTE, MACD alignment, HLI >= 65 and score >= 75.
- Counter-trend BUY/SELL is allowed only with strong confluence (score >= 78, OTE and MACD alignment), preventing the old one-way HTF gate from suppressing BUY entirely.
- Live Smart Context now permits configured Asia/Asia-Europe sessions instead of hard-blocking them.
- No synthetic order-book/footprint/news data is created.

## Important
The backtest result is an in-sample research result because the strict symbol list was motivated by the prior sample. It must be validated out-of-sample before live capital.
