# V30.9.1 — Final Audit / Safety Corrections

## Critical corrections
- Corrected the backtest Fibonacci OTE lower boundary from an accidental 50% setting to the intended **61.8%**.
- Standardized Fibonacci lookback to **72 completed 15m bars** for the current research configuration.
- The backtest now actually uses `score_thr` and the configured Fibonacci parameters from `V30_SELECTED_CONFIG.json`; previously some of these values were not wired into the runner.
- TradFi backtests now receive the asset class so stock/ETF/index and metal/energy/forex session thresholds are applied consistently.
- Live `Smart Context` now receives the detected asset class for the same reason.
- Runtime encrypted state/history persistence was added to the GitHub workflow; hosted runners are ephemeral and local files would otherwise disappear between cycles.
- Telegram signal messages now show Fibonacci lookback, POC/VAH/VAL, MACD alignment, Ichimoku state, OTE gate and order-flow strength.
- WEEX history pagination now sorts each response by timestamp and rate-limits requests modestly.
- `research_vp.py` no longer executes research automatically on import.
