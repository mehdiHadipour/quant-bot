# AI Quant Bot v12.3 (نسخه اصلاح‌شده)

ربات معاملاتی تحلیلی (سیگنال‌دهی، نه سفارش خودکار) که به‌طور کامل روی **GitHub Actions**
اجرا می‌شود. یعنی هیچ سروری یا اجرای دائمی روی گوشی لازم نیست؛ گوشی اندروید شما فقط برای
مدیریت مخزن (از طریق اپ GitHub یا مرورگر) و دریافت سیگنال‌ها در تلگرام استفاده می‌شود.

## ⚠️ هشدار امنیتی مهم (حتماً بخوانید)

در فایل اصلی که ارسال کرده بودید (`config.py`)، یک **توکن ربات تلگرام و chat id واقعی
به‌صورت hardcode** داخل کد نوشته شده بود. این یعنی اگر آن نسخه را در یک مخزن گیت‌هاب
(حتی خصوصی) قرار می‌دادید، توکن لو می‌رفت و هرکسی می‌توانست از ربات تلگرام شما سوءاستفاده
کند. در این نسخه:

- توکن هاردکد **حذف شد** و ربات فقط از GitHub Secrets می‌خواند.
- **پیشنهاد می‌شود همین حالا** با @BotFather دستور `/revoke` را برای توکن قبلی بزنید و
  یک توکن جدید بگیرید، چون توکن قبلی از طریق فایل آپلودی قابل مشاهده بوده است.

## ✅ باگ‌هایی که رفع شد

1. **باگ بحرانی (کرش کامل ربات):** در `main.py` خط `if not df_1h or not df_4h` روی یک
   `DataFrame` واقعی اجرا می‌شد که باعث خطای `ValueError: The truth value of a DataFrame
   is ambiguous` می‌شد — یعنی به محض دریافت موفق داده، کل اجرا کرش می‌کرد. اصلاح شد به
   بررسی صریح `is None`.
2. **باگ تاریخچه معاملات:** در نسخه قبلی، معاملات بسته‌شده قبل از این‌که در تاریخچه
   (`history.csv`) ذخیره شوند، از لیست state حذف می‌شدند، پس شرط جست‌وجوی معاملهٔ بسته
   همیشه خالی برمی‌گشت و چیزی در تاریخچه ثبت نمی‌شد. اکنون معاملات بسته‌شده مستقیماً
   برگردانده و ثبت می‌شوند.
3. **مسدودشدن جغرافیایی Binance (HTTP 451):** ران‌رهای GitHub Actions در دیتاسنترهای
   آمریکا هستند و گاهی `api.binance.com` آن‌ها را مسدود می‌کند. حالا ربات ابتدا از
   `data-api.binance.vision` (میرور رسمی و بدون محدودیت جغرافیایی Binance برای داده‌های
   عمومی) استفاده می‌کند و در صورت خطا به چند آدرس دیگر برمی‌گردد.
4. **دو زمان‌بندی هم‌پوشان در Workflow:** دو `cron` که هم‌زمان (هر ۴ ساعت) با هم اجرا
   می‌شدند و می‌توانستند باعث دو اجرای موازی و تداخل در `git push` شوند، به یک زمان‌بندی
   ساده (هر ۱۵ دقیقه) تبدیل شد، به‌همراه `concurrency` برای جلوگیری از اجرای هم‌زمان.
5. **کرش روی state قدیمی/ناقص:** اگر فایل state کلیدهایی مثل `stats.streak` را نداشت،
   کد با `KeyError` متوقف می‌شد. حالا مقادیر پیش‌فرض تضمین می‌شوند.
6. پوشه‌های خالی `state/` و `data/` در گیت ردیابی نمی‌شدند (گیت پوشهٔ خالی را ذخیره
   نمی‌کند)؛ فایل `.gitkeep` اضافه شد.
7. نسخه‌های کتابخانه‌ها در `requirements.txt` پین شدند تا با آپدیت‌های ناگهانی numpy/pandas
   خراب نشود.
8. مدیریت خطا: اگر تحلیل یک ارز با خطا مواجه شود، کل چرخه متوقف نمی‌شود؛ فقط همان ارز رد
   می‌شود. خطاهای غیرمنتظره هم به تلگرام گزارش می‌شوند.

## ساختار پروژه

- `.github/workflows/bot.yml` — Workflow گیت‌هاب اکشن (هر ۱۵ دقیقه اجرا می‌شود)
- `main.py` — نقطهٔ ورود و منطق اصلی چرخه
- `config.py` — خواندن تنظیمات از Secrets (بدون هیچ مقدار هاردکد)
- `data_engine.py` — دریافت کندل از Binance با چند مسیر جایگزین
- `indicators.py` — تحلیل تکنیکال و امتیازدهی سیگنال
- `trade_monitor.py` — بررسی معاملات باز و مدیریت circuit breaker
- `state_manager.py` — ذخیرهٔ رمزنگاری‌شدهٔ state
- `telegram.py` — ارسال پیام به تلگرام

## راه‌اندازی (قدم‌به‌قدم، از طریق گوشی هم قابل انجام است)

1. یک مخزن جدید در GitHub بسازید (خصوصی پیشنهاد می‌شود چون state شامل نتایج معاملات است).
2. تمام فایل‌های این پروژه را در آن مخزن آپلود کنید (از اپ GitHub یا مرورگر گوشی هم می‌شود:
   Add file > Upload files).
3. در تلگرام یک ربات جدید با @BotFather بسازید و توکن آن را بردارید؛ chat id خودتان را از
   @userinfobot یا مشابه آن بگیرید.
4. کلید رمزنگاری بسازید (در ترمینال هر کامپیوتری یا Termux روی اندروید):
   ```bash
   pip install cryptography
   python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```
5. در مخزن گیت‌هاب بروید به: **Settings > Secrets and variables > Actions > New repository
   secret** و سه مقدار زیر را اضافه کنید:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT`
   - `ENCRYPTION_KEY`
6. در **Settings > Actions > General > Workflow permissions**، گزینهٔ
   **"Read and write permissions"** را فعال کنید (لازم است تا ربات بتواند state را کامیت کند).
7. به تب **Actions** بروید، workflow را فعال کنید و یک بار با **Run workflow** به‌صورت دستی
   اجرا کنید تا مطمئن شوید همه‌چیز درست کار می‌کند.
8. از این پس ربات هر ۱۵ دقیقه به‌صورت خودکار اجرا می‌شود، حتی اگر گوشی/کامپیوتر شما خاموش
   باشد — چون کاملاً روی سرورهای GitHub اجرا می‌شود.

## نکات مهم

- این ربات فقط **سیگنال تحلیلی** می‌فرستد و **هیچ سفارشی را به‌صورت خودکار در صرافی ثبت
  نمی‌کند**؛ تصمیم معامله بر عهدهٔ خود شماست.
- زمان‌بندی `cron` گیت‌هاب تضمین‌شده و دقیق‌به‌ثانیه نیست؛ در بازه‌های پرترافیک ممکن است
  چند دقیقه تأخیر داشته باشد — این محدودیت خود GitHub است.
- برای شخصی‌سازی نمادهای معاملاتی، یک Secret یا Variable با نام `SYMBOLS` و مقداری مثل
  `BTCUSDT,ETHUSDT` تنظیم کنید.
