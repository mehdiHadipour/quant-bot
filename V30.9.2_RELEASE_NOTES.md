# Quant Bot V30.9.2 — Unified Config / Backtest Research Release

## What changed
- Added `manual_settings.json` as the single manual configuration source.
- Live strategy (`indicators.py`) reads the same settings used by the unified backtest.
- Added per-tool `enabled`, `mode` (`score`/`hard`), and `weight` controls for the scoring layer.
- Added manual switches for the principal live hard gates: ADX, low-ATR, HTF alignment, Fibonacci OTE, short-term EMA, Smart Context, strict-symbol, negative-session, and countertrend.
- Added `unified_backtest.py`, which calls the same `indicators.analyze_market()` used by the live bot. Only order execution/exit simulation differs.
- Backtest uses completed 1H bars and derives 4H/1D context from the same OHLCV source to avoid signal look-ahead.
- News is disabled in the research runner because external news is not reproducible historically.

This release is a research/deployment-candidate build, not a claim of profitability. The unified backtest below is the authoritative regression result for this release.
